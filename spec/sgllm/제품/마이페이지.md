# 마이페이지 문서

## 개요

"마이페이지" 기능은 서강대학교 사용자를 위한 개인 계정 관리 허브로 기능합니다. 이 중앙화된 대시보드를 통해 사용자는 계정 설정을 종합적으로 모니터링하고 제어할 수 있습니다.

## 주요 기능

### 크레딧 상태 섹션

사용자는 사용 가능한 총 크레딧을 한눈에 볼 수 있습니다. 시스템은 세 가지 크레딧 유형을 표시합니다:

- **할당된 크레딧**: 구독 계층에 따른 월별 할당
- **구매한 크레딧**: 별도로 취득한 크레딧(만료 날짜 포함)
- **총 가용**: 두 크레딧 유형의 합계

정보 아이콘을 마우스 오버하면 자세한 분석을 제공합니다.

### 사용량 개요

시각적 차트는 세 가지 범주에 걸친 월별 크레딧 소비를 표시합니다:

- 채팅 크레딧 (대화 토큰)
- 웹 검색 크레딧 (검색 기능)
- 이미지 크레딧 (이미지 생성)

이 시각화는 사용자가 기능 사용 패턴을 이해하고 크레딧 할당을 최적화하는 데 도움이 됩니다.

### 구매 내역

페이지 매김된 표는 다음 세부정보가 포함된 크레딧 거래를 나열합니다:

- 구매 및 소비된 수량
- 거래 날짜
- 결제 금액
- 유효 사용 기간
- 영수증 다운로드 옵션 (사용 가능한 경우)

## 디자인 요소

인터페이스는 사용자 정의 스타일링이 있는 Chakra UI 구성 요소를 사용합니다. 페이지는 특정 색상 변수(기본 파란색 #1751D0, 지원 그레이, 악센트 색상)가 있는 라이트 테마를 사용합니다.

## 언어 지원

문서는 영어와 한국어로 존재하며, 언어 선호도 간 접근성을 위한 완전한 병렬 콘텐츠 구조를 갖습니다.
