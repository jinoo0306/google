# 영상 생성 문서

## 개요

플랫폼은 주요 AI 모델로 강화된 고급 비디오 생성 기능을 제공합니다. 사용자는 텍스트 프롬프트를 입력하고 여러 전문화된 모델에서 선택하여 영상 콘텐츠를 생성할 수 있습니다.

## 주요 기능

**모델 선택**: 시스템은 OpenAI(Sora 2, Sora 2 Pro), Google(Veo 3.1, Veo 3.1 Fast) 및 Kling, ByteDance, MiniMax 등의 다른 제공자의 비디오 생성 모델을 통합합니다.

**시작 프로세스**:
1. 대시보드에서 비디오 생성 메뉴 접근
2. 원하는 비디오 스타일과 일치하는 AI 모델 선택
3. 장면, 카메라 앵글, 조명, 움직임의 자세한 설명 입력
4. 비디오 매개변수 구성 (길이, 프레임 비율, 해상도)
5. 전용 버튼을 통해 생성 시작

## 고급 기능

**참조 이미지**: 기존 이미지를 업로드하여 비디오 생성을 안내하고 프로젝트 전체에 걸쳐 일관된 시각 정체성을 유지합니다.

**히스토리 관리**: 생성된 비디오는 전체 메타데이터와 함께 저장되어 다운로드, 재생 검토, 사용하지 않는 콘텐츠 삭제가 가능합니다.

**크레딧 시스템**: 비디오 생성은 모델 성능 및 선택한 매개변수에 따라 크레딧을 소비합니다. 사용자는 생성 전에 예상 비용을 확인해야 합니다.
