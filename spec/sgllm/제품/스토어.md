# 스토어 페이지

## 개요

**스토어**는 사용자가 맞춤형 챗봇을 발견하고 공유할 수 있는 커뮤니티 마켓플레이스입니다. 앱 스토어와 유사하게 기능하며, 제작자와 사용자 모두가 공유된 AI 도구의 이점을 누릴 수 있습니다.

## 주요 기능

### 사용자용
- 다양한 주제 및 사용 사례에 걸쳐 챗봇 탐색
- 특정 기능의 도구 검색
- 커뮤니티 생성 솔루션 접근

### 제작자용
- 맞춤형 챗봇을 스토어에 발행하여 타인과 공유
- 특정 사용자 그룹 또는 전체 커뮤니티에 도달
- 비즈니스 도구 애플리케이션 및 팀 협업 활성화

## 발행 프로세스

챗봇을 스토어에 나열하려면:

1. **스튜디오에서 생성**: 스튜디오 플랫폼을 사용하여 챗봇 구축
2. **공개 상태 설정**: 가시성 및 공개 공유 설정 구성
3. **관리자 승인**: 관리자 검토 및 승인을 위해 제출
4. **자동 배포**: 승인 후 챗봇이 선택한 범주 및 그룹에 나타남

## 요구사항

- 챗봇은 먼저 스튜디오에서 생성되어야 함
- 공개 접근 구성 필수
- 가시성 전에 관리자 승인 필수
- 선택한 범주 및 그룹 내 사용자에게 자동 노출
