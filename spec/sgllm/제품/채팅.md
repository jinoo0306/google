# 채팅 기능 가이드

## 개요

서강대학교의 AI 채팅 플랫폼 문서로, 여러 고급 AI 모델과 기능을 통합된 인터페이스로 제공합니다.

## 주요 기능

### 챗봇 선택 메뉴

"글로벌 최첨단 AI와 맞춤형 챗봇, 단일 창에서 자유롭게 접근 가능합니다."

사용자는 GPT-5, Claude, Gemini 등의 모델과 기관 특화 맞춤 챗봇 사이에서 대시보드 메뉴를 통해 전환할 수 있습니다.

### 챗봇 정보 패널

인터페이스는 다음을 표시합니다:
- 시각적 정체성 및 공식 이름
- 기술 모델 사양
- 개인정보 설정 (개인 또는 공유)
- 현재 사용 지표
- 태그를 통한 지원 기능
- 토큰 단위의 세션 용량
- 크레딧 소비율
- 릴리스 날짜
- 활성 프로모션

### 작업 모드

특화된 모드는 특정 워크플로우를 위한 응답을 최적화합니다:

- **번역**: 자연스럽고 정확한 언어 변환
- **요약**: 긴 콘텐츠를 요점으로 압축
- **코딩**: 개발 중심 예제와 지침
- **이미지 분석**: 업로드된 이미지의 텍스트 및 콘텐츠 인식
- **시험 준비**: 맞춤형 연습 자료 및 학습 자료
- **논문 분석**: 학술 연구 요약 및 설명
- **발표 설계**: 구조화된 발표 계획
- **보고서 작성**: 체계적인 개요 및 프레임워크 작성

### 웹 검색

최근 이벤트, 정책 변경, 실시간 데이터에 대한 질문에 답하기 위해 현재 인터넷 정보를 검색하며, 출처 인용을 제공합니다.

### 심화 사고

"복잡한 문제나 고급 질문을 논리적 사고 과정을 기반으로 분석합니다" (Claude 전용 기능).

### 파일 업로드 지원

문서(.pdf, .docx, .pptx, .hwp), 이미지(.jpg, .png, .gif, .webp), 스프레드시트(.csv, .xlsx), 코드 파일, 구성 형식을 받으며, 파일당 최대 200MB입니다.

OCR, 레이아웃 분석, 복잡한 표 인식으로 강화됩니다.

### 이미지 생성

사용자는 채팅에서 원하는 이미지를 설명하여 콘텐츠, 디자인, 발표 목적의 시각 자료를 생성할 수 있습니다.

## 사용 참고사항

- 채팅 전송에는 텍스트 입력이 필요합니다
- 3분 후 응답 시간 초과 시 자동 중지가 발생합니다
- 입력 콘텐츠는 채팅 전환 시 유지됩니다
