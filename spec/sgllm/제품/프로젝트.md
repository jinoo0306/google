# 프로젝트 문서

## 개요

프로젝트 기능을 통해 사용자는 관련 대화, 지침, 메모리, 파일을 통합 작업 공간에 정리할 수 있습니다. 이 기능은 여러 채팅 세션에서 맥락을 반복해서 설명할 필요성을 제거합니다.

## 주요 기능

**핵심 기능:**
- "관련 대화, 지침, 메모리, 파일을 단일 작업 공간으로 그룹화"
- 모든 대화에 프로젝트 수준 지침 및 메모리 자동 적용
- 모든 프로젝트 토론에 액세스 가능한 중앙화된 파일 관리

## 프로젝트 생성

왼쪽 사이드바의 프로젝트 메뉴에 접속하고 "새 프로젝트"를 클릭합니다. 필수 필드는:

- **프로젝트 이름** (최대 100자)
- **설명** (선택 사항)

## 프로젝트 구조

### 대화 영역

- 프로젝트 이름 및 설명 표시
- 새 대화 시작을 위한 메시지 입력
- 프로젝트 내 기존 대화 목록

### 설정 사이드바

세 가지 주요 구성 요소를 관리합니다:

**지침:** "프로젝트 내 모든 대화에 자동으로 적용되는 AI 지침입니다." 10,000자로 제한되며, 모든 토론에서 일관된 응답 패턴을 설정합니다.

**메모리:** 대화 중 참조되는 컨텍스트 정보로, 최대 5,000자를 지원합니다. AI는 세션 중에 이를 자동으로 업데이트할 수 있습니다.

**파일 관리:** 프로젝트 대화 전체에서 접근할 파일을 업로드합니다. 처리 상태는 업로드 중에 표시되며, 중복 업로드는 방지됩니다.

## 세션 관리

사용자는 기존 채팅 세션을 프로젝트로 이동하거나 제거할 수 있습니다. 제거되면 대화는 "내 채팅 히스토리"에서 삭제되지 않고 액세스 가능합니다.

## 프로젝트 유지보수

프로젝트는 편집(이름/설명 변경) 또는 삭제할 수 있습니다. 삭제하면 프로젝트 구조만 제거되고, 관련 대화는 "내 세션"으로 이동됩니다.
