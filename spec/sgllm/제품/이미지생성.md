# 이미지 생성 - 문서

## 개요

이미지 생성 기능을 통해 사용자는 여러 AI 모델을 사용하여 텍스트 프롬프트를 통해 이미지를 생성할 수 있습니다. 문서에 따르면: **"OpenAI부터 Runway까지. 최신 글로벌 AI 엔진이 당신의 상상을 기다립니다"** (OpenAI에서 Runway까지, 최신 글로벌 AI 엔진이 기다립니다).

사용자는 간단한 텍스트 설명을 입력할 수 있으며, 시스템은 포토리얼리즘에서 예술적 스타일까지의 스펙트럼에 걸쳐 아이디어를 시각화합니다.

## 지원되는 모델

플랫폼은 8개의 이미지 생성 모델을 지원합니다:

| 모델 | 제공자 | 최적 사용 |
|------|--------|----------|
| Nano Banana | Google | 소셜 미디어, 제품 편집, 캐릭터 시리즈 |
| Nano Banana Pro | Google | 인포그래픽, 교육 자료 |
| GPT Image 1 | OpenAI | 컨셉 아트, 일러스트, 포스터 |
| GPT Image 1 Mini | OpenAI | 썸네일, 초안, 대량 자산 |
| FLUX 1.1 [pro] | FLUX | 광고 배너, 목업, 마케팅 |
| Seedream 4.0 | ByteDance | 교육 일러스트, 다이어그램 |
| Gen-4 Image | Runway | 스토리보드, 캐릭터 시트 |
| SDXL | Stability AI | 개인 프로젝트, 스타일 실험 |

## 주요 기능

**프롬프트 최적화**: 시스템은 간단한 키워드를 자동으로 상세하고 전문적인 프롬프트로 변환하여 경험이 적은 사용자가 고품질 이미지를 생성하도록 도와줍니다.

**참조 이미지**: 사용자는 기존 이미지를 스타일 가이드로 업로드하여 일관성을 유지하거나 새로운 생성에 특정 시각적 방식을 적용할 수 있습니다.

**편집 기능**: 전체를 다시 생성하는 대신 사용자는 선택적으로 영역을 다시 그리거나, 객체를 제거하거나, 요소를 추가하거나, 스타일을 수정할 수 있습니다.

**히스토리 관리**: 모든 생성물은 원본 프롬프트와 함께 자동으로 저장되어 사용자가 과거 작업을 검토하거나, 고해상도로 다시 다운로드하거나, 동일한 매개변수를 사용하여 재생성할 수 있습니다.

## 크레딧 시스템

이미지 생성은 선택한 모델과 해상도, 품질 등의 매개변수에 따라 크레딧을 소비합니다. 정확한 크레딧 비용은 생성 전에 표시되며, 생성이 실패하면 크레딧이 차감되지 않습니다.
