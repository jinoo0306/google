# 스튜디오 문서

## 개요

스튜디오는 맞춤형 챗봇을 생성하고 관리하기 위한 개인 작업 공간입니다. 문서에 따르면 "스튜디오는 맞춤형 챗봇을 생성하고 관리하기 위한 개인 작업 공간입니다. 🤖"

## 주요 기능

### 챗봇 생성

사용자는 다음을 포함한 간단한 프로세스를 통해 챗봇을 구축할 수 있습니다:

- **프로필 이미지**: 봇의 시각적 식별자 설정
- **이름**: 한국어 또는 영어로 선택
- **주요 기능**: 스토어 가시성을 위한 봇의 기능 설명
- **언어 모델**: 사용 가능한 AI 모델에서 선택
- **모델 설정**: 온도 및 Top P 매개변수 조정
- **문서 업로드**: 파일로 봇 학습
- **테스트 채팅**: 배포 전 봇 동작 미리보기

### 지원되는 파일 유형

플랫폼은 여러 범주에 걸쳐 광범위한 파일 형식을 받습니다:

| 범주 | 예제 |
|------|------|
| 문서 | PDF, DOCX, PPTX, HWP, HWPX |
| 데이터 | CSV, XLS, XLSX, TSV |
| 코드 | Python, JavaScript, Java, C++, PHP, Go, Rust 등 |
| 스크립트 | Bash, PowerShell, 배치 파일 |
| 웹 | HTML, CSS |
| 구성 | JSON, XML, YAML, TOML, 속성 |

**한계**: 문서당 최대 200MB

### 모델 매개변수 설명

**온도**: 응답 창의성을 제어합니다. 낮은 값은 "정확하고 집중된 응답"을 생성하며, 높은 값은 "더 표현력 있고 창의적인 응답"을 허용합니다. 권장: 0.7

**Top P**: 단어 다양성을 관리합니다. 낮은 설정은 초점을 강조하며, 높은 값은 풍부함을 증가시킵니다. OpenAI의 경우 1.0, Llama의 경우 0.7을 권장합니다.

## 권한 관리

### 공개 챗봇

공개 봇은 스토어 목록에 표시되기 전에 관리자 승인이 필요합니다. 승인되면 지정된 사용자 그룹에 액세스할 수 있습니다. 문서에 따르면: "챗봇이 공개 중인 동안에는 편집할 수 없습니다."

### 비공개 챗봇

비공개 봇은 제작자에게만 독점적이며 무제한 편집 유연성을 제공합니다. 제작자만 액세스하고 수정할 수 있습니다.

## 고급 기능

### 공개 페이지 공유

사용자는 스토어 발행 없이 외부 대상을 위해 공유 가능한 URL을 생성할 수 있으나, 크레딧 사용은 제작자의 계정에 적용됩니다.

### 위젯 임베드

JavaScript 코드를 통해 웹사이트 통합이 가능하며, 맞춤형 색상과 제목으로 오른쪽 아래 모서리에 채팅 버튼을 표시합니다.
