# 발표 기능 문서

## 개요

발표 기능은 "당신의 주제에 맞게 자동으로 발표 슬라이드를 생성"하는 AI 기반 도구입니다. 사용자는 주제나 텍스트를 입력하고 복잡한 디자인 작업 없이 완전하고 전문적인 슬라이드를 받습니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 자동 슬라이드 생성 | "AI가 당신의 주제로 구조화된 슬라이드를 자동으로 생성" |
| 슬라이드 수 제어 | 원하는 슬라이드 정확한 수 지정 |
| 참조 문서 | 보고서나 문서를 콘텐츠에 통합 |
| 디자인 스타일 선택 | 특정 스타일 요청 (미니멀, 트렌디 등) |
| 실시간 미리보기 | 생성된 슬라이드를 오른쪽 패널에서 즉시 보기 |

## 인터페이스 레이아웃

**왼쪽 패널 (채팅):** 사용자가 주제를 입력하고 AI와 상호작용하여 슬라이드를 생성하는 곳이며, 대화를 통해 수정을 요청할 옵션이 있습니다.

**오른쪽 패널 (슬라이드 뷰어):** 미리보기, 편집, 발표, 내보내기 기능이 있는 생성된 슬라이드를 보고 관리하는 영역입니다.

## 사용 방법

1. 사이드바의 발표 메뉴 클릭
2. 왼쪽 채팅 입력에 원하는 주제 입력
3. 오른쪽 패널에서 AI 생성 결과 검토
4. 필요하면 채팅을 통해 수정 요청
5. 완성된 슬라이드 발표 또는 내보내기

## 내보내기 옵션

- **PPTX:** "Microsoft PowerPoint 형식으로 내보내기" (PowerPoint나 Google Slides에서 추가 편집 가능)
- **PDF:** "PDF 형식으로 내보내기. 공유 또는 인쇄에 유용"

## 사용 사례

투자 피치 덱, 성과 보고서, 브랜드 전략 발표, 여행 일정 등의 예가 포함됩니다.

**팁:** "슬라이드 수, 디자인 스타일, 참조 자료가 구체적할수록 더 정확한 결과를 얻을 수 있습니다."
