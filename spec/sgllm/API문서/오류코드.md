# Mindlogic API 오류 코드 문서

## 개요

이 문서 페이지는 Mindlogic API의 HTTP 오류 코드 및 응답 형식을 자세히 설명하여 개발자가 통합 시 문제를 해결할 수 있도록 도와줍니다.

## HTTP 오류 코드

API는 특정 상태 코드를 가진 표준화된 오류 응답을 반환합니다:

| 상태 | 오류 유형 | 메시지 | 의미 |
|------|---------|--------|------|
| 400 | invalid_request_error | "요청 본문의 JSON이 올바르지 않음" | 잘못된 JSON 형식 |
| 400 | invalid_request_error | "필수 매개변수 누락: 'model'" | 필수 필드 없음 |
| 401 | authentication_error | "인증 헤더가 제공되지 않음" | 인증 헤더 누락 또는 잘못됨 |
| 401 | authentication_error | "Bearer 토큰이 제공되지 않음" | 잘못된 bearer 토큰 |
| 401 | authentication_error | "API 키가 올바르지 않음" | 무단 API 자격증명 |
| 402 | insufficient_quota | "할당량 초과됨" | 요청 한도 도달 |
| 403 | permission_denied | "모델에 대한 접근 불가" | 불충분한 접근 권한 |
| 404 | invalid_request_error | "모델을 찾을 수 없음" | 요청된 리소스 불가 |
| 429 | rate_limit_exceeded | "속도 제한 초과됨" | "분당 60개 요청 한도 초과" |
| 503 | service_unavailable | "서비스 일시적으로 이용 불가" | 시스템 다운타임 |
| 다양함 | api_error | "제공자 API 오류" | OpenAI/Google/Anthropic 서비스 실패 |

## 오류 응답 형식

모든 오류는 일관된 JSON 구조를 따릅니다:

```json
{
  "detail": {
    "code": 400,
    "message": "invalid_request_error - 요청 본문의 JSON이 올바르지 않음"
  }
}
```

메시지는 다음 패턴을 사용합니다: `"{error_type} - {message}"`

## 지원 리소스

API 키는 API 소개 페이지를 통해 사용 가능합니다. 지속적인 오류는 고객 지원팀에 직접 문의할 필요가 있습니다.
