# Mindlogic API 문서

## 개요

Mindlogic 문서 페이지는 통합 AI API 플랫폼에 접근하고 사용하기 위한 포괄적인 지침을 제공합니다.

## 핵심 내용

### API란?

"API(응용 프로그래밍 인터페이스)는 사용자가 코드를 통해 소프트웨어나 시스템의 기능을 쉽게 호출할 수 있도록 도와주는 사용자 설명서이자 통신 채널입니다."

플랫폼을 통해 개발자는 텍스트 요약 또는 이미지 생성과 같은 요청을 애플리케이션 내에 통합하고 표준화된 인터페이스를 통해 결과를 받을 수 있습니다.

### 주요 기능

서비스는 OpenAI, Anthropic, Google을 포함한 주요 언어 모델 제공자에 대한 통합 접근 방식을 제공합니다. 플랫폼은 다양한 사용 사례를 지원합니다:
- 채팅 애플리케이션
- 이미지 생성
- 웹 검색
- 문서 요약

고급 사용자는 복잡한 인프라 설정 없이 완전한 데이터 제어를 유지하면서 모델 간 전환할 수 있는 이점을 누릅니다.

### 시작 프로세스

**3단계 설정:**

1. **등록**: Mindlogic 플랫폼에서 가입 프로세스 완료
2. **API 키 생성**: 개발자 설정에 접근하여 키를 생성하고 안전하게 저장
3. **연결 테스트**: curl 명령을 실행하여 연결 확인

### 중요 경고

"생성 후에는 이 키를 다시 볼 수 없습니다. 안전한 장소에 저장해주세요."

### 지원되는 API

문서는 다양한 모델 제공자(OpenAI, Google, Anthropic)를 통해 텍스트 생성, 이미지 생성, 편집을 지원하는 여러 API 엔드포인트를 참조합니다.
