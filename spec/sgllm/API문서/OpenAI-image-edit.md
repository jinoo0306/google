# OpenAI 이미지 편집 API 문서

## 개요

OpenAI 이미지 편집 엔드포인트는 `gpt-image-1` 모델을 사용하여 사용자 제공 이미지와 텍스트 프롬프트를 기반으로 이미지 수정 및 확장을 허용합니다.

**주요 기능:**
- 편집 가능 영역 정의를 위한 마스크 이미지 지원
- 투명 배경 옵션
- 여러 출력 크기 및 고해상도 기능
- 배치 처리 (최대 16개 이미지)

**리소스:**
- [OpenAI Python SDK](https://github.com/openai/openai-python)
- [공식 이미지 API 문서](https://platform.openai.com/docs/api-reference/images/createEdit)

## API 엔드포인트

**POST** `/v1/api/openai/images/edit`

업로드된 파일과 텍스트 설명을 기반으로 이미지를 수정하거나 확장합니다. API는 마스크 기반 편집을 지원하며 투명 배경 및 출력 해상도에 대한 다양한 사용자 정의 옵션을 제공합니다.

## 요청 요구사항

### 헤더
```
Authorization: Bearer {api-key}
```

### 매개변수

| 매개변수 | 유형 | 필수 | 세부사항 |
|-----------|------|----------|---------|
| **image** | 문자열 또는 배열 | 예 | 편집할 이미지: PNG/WebP/JPG, 최대 25MB, 최대 16개 파일 |
| **prompt** | 문자열 | 예 | 원하는 편집의 텍스트 설명 (최대 32,000자) |
| **model** | 문자열 | 아니오 | 모델 선택: `gpt-image-1` |
| **n** | 정수 | 아니오 | 생성할 이미지 수 (1–10, 기본값: 1) |
| **size** | 문자열 | 아니오 | 출력 크기: `1024x1024`, `1536x1024`, `1024x1536`, `auto` |
