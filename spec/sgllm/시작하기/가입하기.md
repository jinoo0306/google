# 소강대학교 가입 가이드

## 개요

서강대학교 플랫폼은 보안과 관리 제어를 우선시합니다. **일반 자가 등록은 제한됩니다**. 기관은 세 가지 등록 방식을 제공합니다:

1. 관리자 승인 요청
2. 관리자 초대
3. 통합 SSO 시스템

## 등록 방법

### 관리자 승인 요청

관리자 초대나 SSO 접근권이 없는 사용자는 관리자 승인을 받아야 합니다.

**절차:**
- 서강대학교 메인 페이지에 접속하고 등록 양식을 작성합니다
- 참고: "승인될 때까지 로그인할 수 없습니다"
- 승인 후 등록된 주소로 이메일 확인이 전송됩니다
- 등록된 자격증명을 사용하여 로그인합니다

**지원:** 승인 확인을 받지 못했거나 로그인이 실패하면 관리자에게 문의하세요.

### 관리자 초대

관리자는 이메일을 통해 사용자를 직접 초대할 수 있습니다.

**절차:**
- 등록된 "이메일 주소"와 "임시 비밀번호"가 포함된 초대장을 받은편지함에서 확인합니다
- 초대 수락 버튼을 클릭하여 등록 페이지에 접속합니다
- 임시 비밀번호를 입력하여 가입을 완료합니다
- **중요:** 이메일 링크만 사용하세요. 직접 로그인은 작동하지 않습니다
- 첫 로그인 후 프로필 메뉴를 통해 임시 비밀번호를 변경합니다

**지원:** 초대 이메일이 도착하지 않으면 관리자에게 문의하세요.

### 통합 SSO 로그인

SSO 통합이 있는 조직은 별도의 등록 없이 기업 자격증명을 사용하여 로그인할 수 있습니다.

플랫폼은 SSO를 지원하여 관리 부담을 최소화하고 사용자 편의를 강화합니다. 이 기능을 활성화하려면 조직의 서강대학교 담당자에게 문의하세요.

**지원:** SSO 로그인이 실패하면 관리자에게 문의하세요.
