# 개인정보보호 및 이용약관

## 페이지 개요

이 문서 페이지는 FactChat 플랫폼의 서강대학교 인스턴스에 대한 법적 계약에 접근합니다.

## 주요 내용

페이지는 간단한 법적 자료 섹션을 제시합니다:

### 사용 가능한 문서

1. **개인정보보호정책** - 개인정보가 어떻게 수집, 사용, 보호되는지 설명합니다
2. **이용약관** - 플랫폼 사용의 규칙과 조건을 설정합니다

두 문서 모두 AWS S3 저장소에서 PDF 다운로드로 사용 가능합니다.

## 네비게이션 컨텍스트

- **플랫폼**: FactChat (서강대학교 인스턴스)
- **마지막 업데이트**: 2025년 4월 24일
- **언어 지원**: 한국어 및 영어 버전 사용 가능
- **문서 유형**: 지원/법적 섹션

## 관련 페이지

사용자는 다음으로 이동할 수 있습니다:
- FAQ 섹션 (이전 페이지)
- API 문서 (다음 페이지)
