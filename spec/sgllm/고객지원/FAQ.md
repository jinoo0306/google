# FAQ - 자주 묻는 질문

## 페이지 개요

이것은 Mindlogic Docs 플랫폼의 FAQ(자주 묻는 질문) 페이지이며, 서강대학교 테넌트가 FactChat 제품을 사용합니다.

## 추출된 FAQ 내용

### 영어 버전

**Q: FactChat이 PDF와 이미지를 학습할 수 있나요?**
A: "예. FactChat은 PDF 문서, 텍스트 파일, 특정 유형의 이미지에서 텍스트를 추출할 수 있습니다."

**Q: 특정 부서용 챗봇을 만들 수 있나요?**
A: "물론입니다. 사용자 그룹을 할당하고 접근 권한을 관리할 수 있습니다."

**Q: 모바일이나 태블릿에서 사용할 수 있나요?**
A: 플랫폼은 별도의 앱 설치 없이 모바일 및 태블릿 브라우저(Safari, Chrome 등)를 지원합니다. 홈 화면에 추가하면 앱 같은 경험을 할 수 있습니다.

- **iOS**: Safari에서 열기 → 공유(□↑) 탭 → '홈 화면에 추가'
- **Android**: Chrome에서 열기 → 메뉴(⋮) 탭 → '홈 화면에 추가'

### 한국어 버전

**Q: PDF나 이미지도 학습 가능한가요?**
A: "네. PDF, 텍스트 문서, 일부 이미지의 텍스트도 학습 가능합니다."

**Q: 부서별 전용 챗봇을 만들 수 있나요?**
A: "네. 사용자 그룹 설정을 통해 전용 챗봇을 만들고 접근 권한을 설정할 수 있습니다."

**Q: 모바일이나 태블릿에서도 사용할 수 있나요?**
A: 유사한 모바일/태블릿 접근성과 iOS 및 Android 지침이 제공됩니다.
